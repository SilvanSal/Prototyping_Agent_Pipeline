# Error Registry

## Purpose
This file documents non-trivial bugs, failure patterns, and their fixes encountered during development. **Before debugging a new error, check here first.**

Phase R reads this file to classify errors as pipeline-caused (P-*) or domain-caused (D-*) and generate improvement recommendations.

## Format
Each entry: Error signature → Root cause → Fix applied → Affected tasks → Date.
